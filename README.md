# TourGuide

TourGuide is a TypeScript-first workspace for guided code tours generated by AI agents and rendered by local viewers.

The canonical artifact is strict JSON. Agents generate tour JSON, validators check it, and viewers render it. The first viewer is a standalone terminal UI built around reusable components that can later be mounted inside OpenCode.

## Packages

- `packages/schema` owns the canonical JSON Schema, TypeScript types, fixtures, and validation helpers.
- `packages/core` normalizes authored tours into renderer-friendly models.
- `packages/tui` contains reusable TUI component boundaries and the placeholder renderer.
- `packages/cli` provides the `tourguide` command surface.
- `packages/tourguide.nvim` contains the existing Neovim plugin, preserved as a legacy adapter package.
- `skills/tourguide` contains the JSON-authoring skill contract.

## Commands

```sh
bun install
bun run build
bun run test
bun run tourguide validate packages/schema/fixtures/solid-effects-short.tour.json
bun run tourguide view packages/schema/fixtures/solid-effects-short.tour.json
bun run tourguide context packages/schema/fixtures/solid-effects-short.tour.json --step internal-effect-node
```

## Current Status

This is an early scaffold. The schema, validator, normalizer, CLI, and placeholder TUI are wired. Full OpenTUI rendering, git-aware anchor validation, web viewing, OpenCode integration, and Neovim JSON support are intentionally not implemented yet.
